# Task Manager (Python)

A simple command-line task manager built in Python.  
Users can add tasks, view them, mark them as complete, and delete them.

## 🚀 Features
- Add new tasks
- View all tasks
- Mark tasks as complete
- Delete tasks
- Clean and beginner-friendly code

## 🛠️ Tech Used
- Python
